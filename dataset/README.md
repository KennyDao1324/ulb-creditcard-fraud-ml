# ULB European card-fraud dataset

- Original research group: Machine Learning Group, Université Libre de Bruxelles, with Worldline
- Kaggle distribution: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- Open mirror used by the download script: https://storage.googleapis.com/download.tensorflow.org/data/creditcard.csv
- Type: real, anonymized European card transactions from September 2013
- Expected file: `data/raw/creditcard.csv`

The 28 principal-component fields cannot be interpreted as named business attributes. The raw CSV is ignored by Git.
